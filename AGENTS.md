## AI-контент обязан иметь префикс `[AI]`

Весь AI-сгенерированный контент (commit-сообщения, описания и комментарии
issues/PR) помечается префиксом `[AI]`, чтобы было видно, где работал человек,
а где AI.

Формат коммита:

```text
#<id> [AI] <краткое резюме задачи>


<подробное объяснение: что сделано и почему. Пункт на строку.>
```

## Инструмент работы с задачами

Для работы с задачами (GitHub issues, PR) используй утилиту `gh`.

## Работа с Grafana

Весь работа с Grafana строго через CLI: `./gcx`. Не используй `curl` к API
Grafana напрямую.

## Вебпоиск

Весь вебпоиск — строго через тул `webfetch` на
`https://lite.duckduckgo.com/lite/?q=<urlencoded-запрос>`.

Запрещено: встроенный тул `websearch`, `curl`/`wget`/скрипты, любой другой
способ получения страниц из сети. Даже если запрос-URL уже собран правильно,
скачивать его можно только `webfetch`.
